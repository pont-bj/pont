# Gouvernance

## Rôles

- **Propriétaire et mainteneur principal** : François Mawutô Aboudou ZINSOU. Il détient le projet, la marque (voir [`TRADEMARK.md`](TRADEMARK.md)) et la feuille de route, et a le dernier mot sur les décisions.
- **Mainteneurs** : personnes de confiance disposant des droits de fusion sur tout ou partie du dépôt.
- **Contributeurs** : toute personne dont une contribution est acceptée, après acceptation de [`CLA.md`](CLA.md).

## Décisions

- Les décisions courantes (corrections, petites améliorations) se prennent en revue de PR, par consensus entre mainteneurs.
- Les décisions structurantes (architecture, API publique, licence, modèle économique, nouveaux agrégateurs officiels) sont discutées en issue publique, puis tranchées par le mainteneur principal, avec justification écrite.
- Les décisions de sécurité et de conduite peuvent être traitées en privé.
- Le projet reste gratuit en self-host ; Pont Cloud est une offre payante distincte.

## Devenir mainteneur

Il n'y a pas de droit acquis. Le mainteneur principal peut proposer ce rôle, ou l'accepter sur demande, à une personne qui a, sur plusieurs mois, contribué de façon régulière et de qualité, relu les PR d'autrui avec justesse, respecté le code de conduite et les règles de sécurité. Le rôle peut être retiré en cas d'inactivité prolongée ou de manquement.
