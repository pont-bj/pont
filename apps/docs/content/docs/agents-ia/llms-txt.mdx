---
title: "llms.txt"
description: "L'index de la documentation, lisible par les agents IA."
---

Cette documentation publie un fichier `llms.txt` : une ligne par page, avec son titre, son adresse et sa description. Un agent s'en sert pour trouver la bonne page sans parcourir tout le site.

```
https://<votre-domaine>/docs/llms.txt
```

Le fichier est généré à partir des pages : il ne peut pas être périmé par rapport à la documentation.

<Callout>
Pour qu'il soit aussi servi à la racine du domaine (`/llms.txt`, emplacement que les agents consultent en premier), ajoutez une redirection sur la landing : voir [Monter la doc sous la landing](/guides/monter-sous-la-landing).
</Callout>
