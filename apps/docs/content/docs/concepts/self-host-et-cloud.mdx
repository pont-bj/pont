---
title: "Self-host et Pont Cloud"
description: "Un seul code, deux façons de l'utiliser : gratuit chez vous, payant chez nous."
---

| | Self-host | Pont Cloud |
|---|---|---|
| Prix | **Gratuit à vie** | Payant |
| Disponibilité | Disponible | **Pas encore construit** |
| Où tourne Pont | Votre serveur | Géré par Pont |
| Clés d'agrégateurs | Chez vous (variables d'environnement ou coffre chiffré) | Conservées chiffrées par Pont |
| Webhooks | Reçus par votre serveur | Reçus par Pont, relayés à votre application |
| Dashboard | Sur votre serveur | Hébergé |

Le self-host est le même code open core : rien n'y est bridé pour pousser vers le Cloud. Le Cloud vend la tranquillité (hébergement, sauvegardes, disponibilité), pas des fonctionnalités retenues.

Voir [Pont Cloud](/cloud) pour l'état exact.
