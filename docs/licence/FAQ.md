# FAQ licence de Pont

> Langage simple, **pas un avis juridique**. Le texte qui fait foi est [`LICENSE`](../../LICENSE) (BUSL-1.1 et son Additional Use Grant). Contact : pro@aboudouzinsou.com

**Puis-je utiliser Pont dans ma fintech, en production ?**
Oui, gratuitement, sans limite de chiffre d'affaires, et vous pouvez gagner de l'argent avec.

**Puis-je l'héberger pour mes clients ?**
Oui. Héberger Pont (non modifié) pour des tiers, l'intégrer à vos systèmes, le revendre comme service : c'est gratuit et sans partage de revenu.

**Puis-je écrire un plugin ou un adaptateur d'agrégateur ?**
Oui. Les plugins (`PONT_PLUGINS_DIR`), les adaptateurs (`pont provider new`) et la configuration restent libres, y compris pour un usage commercial, tant que vous ne modifiez pas le code source de Pont lui-même.

**Puis-je modifier Pont pour mes besoins internes ?**
Oui, tant que la version modifiée n'est pas offerte ni distribuée à des tiers.

**Puis-je corriger un bug et l'envoyer au projet ?**
Oui, c'est encouragé. Voir [`CONTRIBUTING.md`](../../CONTRIBUTING.md) et [`CLA.md`](../../CLA.md).

**Puis-je forker Pont pour en faire mon produit payant ?**
Si vous modifiez le code et offrez ou distribuez à des tiers un produit dérivé (même gratuit), il faut une licence commerciale : redevance de 15 à 20 % du revenu du produit dérivé, à négocier ([`LICENSE-COMMERCIAL.md`](../../LICENSE-COMMERCIAL.md)). Écrivez à pro@aboudouzinsou.com. Un fork gardé en interne, ou à usage éducatif ou de recherche, ne demande rien.

**Puis-je utiliser le nom « Pont » et le logo ?**
Non, la marque n'est pas couverte par la licence du code. Voir [`TRADEMARK.md`](../../TRADEMARK.md).

**Que se passe-t-il dans 4 ans ?**
Chaque version se convertit automatiquement en AGPL-3.0-only 4 ans après sa publication. À partir de là, cette version est un logiciel open source classique (copyleft réseau : qui modifie et offre le service doit publier ses modifications). Les nouvelles versions suivent le même calendrier.

**Puis-je dire que Pont est « open source » ?**
Pas aujourd'hui. La BUSL n'est pas approuvée par l'OSI. Dites : « code source disponible, open source (AGPL) après conversion ».

**Pont Cloud a-t-il un droit particulier ?**
Pont Cloud est l'offre du propriétaire. Il n'a pas d'exclusivité sur le code : vous pouvez héberger Pont pour vos clients.

**Que faire si je ne sais pas si mon cas est un « produit dérivé » ?**
Écrivez avant de lancer. Le doute se règle par écrit.
