# Raccourcis clavier du dashboard

Appuyez sur `?` n'importe où pour afficher cette liste dans le dashboard. Les raccourcis sont ignorés quand vous tapez dans un champ.

## Navigation : `g` puis une lettre

Appuyez sur `g`, relâchez, puis sur la lettre dans la seconde qui suit.

| Touches | Page |
|---|---|
| `g` `o` | Vue d'ensemble |
| `g` `p` | Paiements |
| `g` `r` | Retraits |
| `g` `w` | Portefeuilles |
| `g` `l` | Registre |
| `g` `a` | Agrégateurs |
| `g` `d` | Développeurs |
| `g` `s` | Paramètres |

Onglets Développeurs : `g` `c` Cas d'usage, `g` `k` Clés, `g` `h` Webhooks, `g` `j` Journaux.
Onglets Paramètres : `g` `u` Utilisateurs, `g` `x` Rôles, `g` `m` E-mail, `g` `t` Alertes.

Seules les pages auxquelles votre rôle donne accès répondent.

## Recherche et aide

| Touches | Action |
|---|---|
| `/` ou `⌘K` / `Ctrl+K` | Ouvrir la recherche |
| `?` | Afficher l'aide des raccourcis |
| `Échap` | Fermer la recherche ou l'aide |

## Dans une page longue

Le panneau « Sur cette page » (en bas à droite) liste les sections : `1` à `9` saute à la section correspondante, `j` / `k` passent à la suivante / précédente. Le défilement respecte la préférence système « réduire les animations ».
