# @pont/core

Contrat partagé de Pont : modèle de paiement normalisé, statuts et interface ProviderAdapter.

> Statut : version 0.1.0, en développement actif (nom de code « Pont », nom définitif à venir). L'API peut encore changer.

## Installation

```bash
pnpm add @pont/core
```

## Utilisation

Ce paquet est surtout destiné à être utilisé via les autres paquets Pont. Voir la documentation.
